## 📱 About the Project
This is a marker-based WebAR application built using A-Frame and AR.js. When the Hiro marker is detected by the camera, a 3D "Volcano Eruption" scene appears. The scene features animated debris, bouncing lava, and interactive objects that change color or erupt when tapped.
